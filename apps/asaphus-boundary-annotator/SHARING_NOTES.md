# Before sharing an annotation pack

The repository contains only code. A generated annotation pack contains local
extracts from the source CT volume and must follow the source dataset's licence.
Do not publish the pack or upload it to GitHub.

For the first expert review, ask the dataset contributors for permission to use
the blinded excerpts and to invite an independent interpreter. Keep the
`*_PRIVATE_KEY.csv` file yourself. Do not include it in the shared folder or
reveal algorithm results until the returned annotations have been frozen.

The app exports JSON and CSV. Ask each observer to return both files and keep
their original filenames unchanged.
