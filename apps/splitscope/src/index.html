THE QUESTION COMES FIRST

A harder split isn’t
automatically a better split.

Choose a validation design that matches where you will predict. Random holdout tests interspersed observations; a spatial holdout tests a contiguous region; a buffer also removes nearby training observations.

A score gap is not proof of leakage. Test locations, prediction distance and training-set size differ. This lab uses one split per strategy, not cross-validation or an estimate of uncertainty. A regional holdout within one specimen does not test transfer to another specimen.

Read the exact method and limitations

The spatial test set contains the 25% of observations nearest to the selected region centre. The buffered strategy uses those same test points and excludes training points closer than the chosen distance to any test point. Random holdout selects the same number of test points using a seeded shuffle. All splits use the same observed data and kNN settings.

Predictions are weighted by inverse Euclidean distance, using at most k training points. No test values enter fitting. Distances are calculated in the supplied x/y units, without separate axis scaling. Use projected coordinates with the same unit on both axes, not latitude/longitude degrees. Synthetic fields and faceted surfaces are teaching examples, not biological simulations.

Imported data: 20–1,600 rows, unique coordinates, finite numeric x,y,value columns. No categorical groups, temporal validation, automatic buffer selection, hyperparameter tuning or confidence intervals. Use an established validation package for those tasks.

Related work: Roberts et al. (2017), Wadoux et al. (2021), blockCV, scikit-learn.
